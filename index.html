PicoOS

A terminal shell OS for the Raspberry Pi Pico, written in MicroPython.

What is it

PicoOS is an operating system for Raspberry Pi Pico boards and other RP2040 / RP2350 boards.

Works on:

  • Raspberry Pi Pico
  • Raspberry Pi Pico W
  • Raspberry Pi Pico 2
  • Raspberry Pi Pico 2 W
  • any dev board with an RP2040 or RP2350

Features

  • Shell - boots into a command shell instead of the normal REPL. Has ls, cd, cat, mkdir, mv, mount and some more.
  • WiFi - on a Pico W you can install apps and update the system over the internet.
  • Apps - own app format called ".pcs". You can install them from the internet or from files.
  • Config - settings are saved as JSON in /conf. If a file is missing it makes a new one with defaults.
  • Error logging - errors go to the SD card if there is one, if not to the flash.
  • Installer - one command flashes MicroPython and copies everything to the board.

Install

1. clone the repo

git clone https://github.com/patriq128/PicoOS.git

2. install the stuff you need on your pc

pip install mpremote psutil requests

3. run the installer

python installer.py

4. follow what it says and you are done

on linux use sudo for the pip and the installer
